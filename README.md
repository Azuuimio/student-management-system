## **Visual Studio** 常见问题

### 问题一：C4996 报错

#### 解决方法

在项目属性中添加预处理器定义 `_CRT_SECURE_NO_WARNINGS`：

1. 右键项目 → **属性**
2. **C/C++** → **预处理器** → **预处理器定义**
3. 下拉框选择 **“编辑…”**
4. 新增一行：

   ```
   _CRT_SECURE_NO_WARNINGS
   ```

5. 确定保存后重新编译即可。

**原因**：MSVC 将部分标准 C 库函数（如 fopen、scanf、strcpy 等）标记为"弃用"，因其缺乏边界检查而被认为存在安全风险。编译器默认对此类调用发出 C4996 警告。若项目启用了 /WX（将警告视为错误），该警告会被提升为编译错误，导致构建失败。_CRT_SECURE_NO_WARNINGS 是一个编译期静默开关，通过在预处理阶段禁用 CRT 头文件中的弃用标注来消除 C4996 警告。需要注意的是，C4996 是 MSVC 特有的诊断行为，并非 C 标准的要求。

### 问题二：控制台中文乱码

#### 解决方法

在“附加选项”中添加 `/utf-8` 编译选项：

1. 右键项目 → **属性**
2. **C/C++** → **命令行**
3. 在 **“附加选项”** 中输入：

   ```
   /utf-8
   ```

4. 确定保存后重新编译即可。

**原因**：MSVC 编译器在未指定 /utf-8 选项时，默认将源文件编码视为系统本地代码页（简体中文 Windows 下为 GBK/CP936），并将字符串字面量以该编码存入二进制。若此时控制台输出端的活动代码页为 UTF-8 (CP65001)，则程序输出的 GBK 字节流会被终端按 UTF-8 解码，因编码不匹配而导致乱码。
